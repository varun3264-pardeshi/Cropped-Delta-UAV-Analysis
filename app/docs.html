1. Configuration & Mathematical Foundation

The CD-UAV 3.5 is a tailless, clipped (cropped) delta wing unmanned aerial vehicle designed for low-drag loiter, high-speed dash, and autonomous intelligence missions. Because tailless delta configurations lack a separate horizontal stabilizer, all pitch and roll control is performed by trailing-edge elevons acting on a reflexed camber airfoil.

// Wing Area & Aspect Ratio (BSERC Eq. 10.2 & 10.3)
λ = Ct / Cr = 0.15 / 0.90 = 0.16667 (1/6)
S = (b / 2) · Cr · (1 + λ) = (1.50 / 2) · 0.90 · (1 + 0.16667) = 0.7875 m²
AR = b² / S = (1.50)² / 0.7875 = 2.8571 (20/7)
k = 1 / (π · e · AR) = 1 / (π · 0.89 · 2.8571) = 0.1252
// Mean Aerodynamic Chord (MAC, c̄) & Spanwise Location (BSERC Eq. 10.4)
c̄ = (2 / 3) · Cr · [(1 + λ + λ²) / (1 + λ)] = (2/3) · 0.90 · [(1 + 0.1667 + 0.0278) / 1.1667] = 0.6143 m
y_MAC = (b / 6) · [(1 + 2λ) / (1 + λ)] = (1.50 / 6) · [(1 + 2·0.1667) / 1.1667] = 0.2857 m

2. Longitudinal Trim & Static Margin Equilibrium

In unaccelerated level flight, aerodynamic and gravitational forces must satisfy simultaneous lift balance and zero pitching moment about the center of gravity ($C_m = 0$):

// Pitching Moment Equation (Cm = 0):
Cm = Cm0 + Cmα · α + Cmδe · δe = 0
δe_trim = - (Cm0 + Cmα · α) / Cmδe

// Lift & Velocity Equilibrium:
CL_trim = CL0 + CLα · α + CLδe · δe_trim
V_trim = sqrt( (2 · W) / (ρ · S · CL_trim) )

// Drag Polar & Thrust/Power Required:
CD = CD0 + k · (CL_trim)² = 0.030 + 0.1252 · (CL_trim)²
Tr = D = q · S · CD = 0.5 · ρ · V² · S · CD
Pr = Tr · V

3. Multi-Altitude Atmospheric Scaling (ICAO Doc 7488)

The International Standard Atmosphere (ISA) barometric formula establishes density variation across operational altitudes:

ρ(h) = ρ0 · (1 - 2.2558 · 10⁻⁵ · h)^4.2559
At h = 0 m (Sea Level):    ρ = 1.2250 kg/m³
At h = 1,000 m (Low Mtn):  ρ = 1.1116 kg/m³ (90.7% of SL)
At h = 2,000 m (Plateau):  ρ = 1.0065 kg/m³ (82.2% of SL)

%% Trim, Thrust Required, and Power Required Analysis of a Cropped Delta Wing UAV
%% Mentor: Dr. J. Sarathkumar Sebastin (VIT Bhopal University)

clear; clc; close all;

% 1. GEOMETRIC & INERTIAL INPUTS (Certified Project 4 Specification)
Cr = 0.90;                  % Root chord [m]
Ct = 0.15;                  % Tip chord [m]
b  = 1.50;                  % Wingspan [m]
e  = 0.89;                  % Oswald efficiency factor [-]
m  = 3.50;                  % UAV takeoff mass [kg]
g  = 10.0;                  % Gravitational acceleration [m/s^2]
W  = m * g;                 % Weight = 35.00 N
rho_SL = 1.225;             % ISA Sea-Level density [kg/m^3]

% Derived Planform Parameters (BSERC Eq. 10.2 - 10.4)
lambda = Ct / Cr;                                       % Taper ratio = 0.1667 (1/6)
S  = 0.5 * b * Cr * (1 + lambda);                       % Wing area = 0.7875 m^2
AR = (b^2) / S;                                         % Aspect ratio = 2.8571 (20/7)
k  = 1 / (pi * e * AR);                                 % Induced drag factor = 0.1252
MAC = (2/3) * Cr * ((1 + lambda + lambda^2)/(1 + lambda)); % MAC = 0.6143 m

% 2. AERODYNAMIC & STABILITY DERIVATIVES (NASA TM-85767 & Reflex Camber)
CD0  = 0.030;               % Zero-lift parasite drag coefficient [-]
CL0  = 0.000;               % Zero-AoA lift coefficient [-]
Cm0  = +0.010;              % Reflex camber zero-lift pitching moment [-]
CLa  = 2.920;               % Lift curve slope [rad^-1]
CLde = 0.265;               % Elevon lift derivative [rad^-1]
Cma  = -0.292;              % Pitch stability derivative [rad^-1] (SM = 10% MAC)
Cmde = -0.400;              % Elevon pitch control derivative [rad^-1]

% 3. 25-STATE LONGITUDINAL TRIM SWEEP (alpha = 0 deg to 12 deg, step 0.5 deg)
alpha_deg = (0.0 : 0.5 : 12.0)';
alpha_rad = deg2rad(alpha_deg);

% Pitching Moment Equilibrium (Cm = 0): Cm0 + Cma*alpha + Cmde*de = 0
de_rad = -(Cm0 + Cma .* alpha_rad) ./ Cmde;
de_deg = rad2deg(de_rad);

% Trimmed Lift, Velocity, Drag, Thrust Required & Power Required
CL_trim = CL0 + CLa .* alpha_rad + CLde .* de_rad;
V_trim  = sqrt((2 * W) ./ (rho_SL * S .* CL_trim));
CD_trim = CD0 + k .* (CL_trim .^ 2);
Tr      = 0.5 * rho_SL .* (V_trim .^ 2) * S .* CD_trim;
Pr      = Tr .* V_trim;
LD      = CL_trim ./ CD_trim;
Endur_Param = (CL_trim .^ 1.5) ./ CD_trim;

% 4. ELECTRIC PROPULSION & 4S 5000mAh LI-PO SIZING
eta_prop = 0.72; eta_elec = 0.88; P_av = 8.0; E_usable_Wh = 59.20;
P_shaft = Pr ./ eta_prop;
P_batt  = (P_shaft ./ eta_elec) + P_av;
Endurance_min = (E_usable_Wh ./ P_batt) * 60;
Range_km      = (V_trim .* (E_usable_Wh ./ P_batt) * 3600) ./ 1000;
